Purpose of the App:

**BudgetBuddy** is a smart and user-friendly mobile application designed to help individuals track their expenses, set budget goals, and gain control over their personal finances. Our goal is to empower users with the tools and insights needed to manage their money effectively.

This app supports users by:
- Allowing registration and login for personalized budget tracking.
- Managing expense categories.
- Logging expenses with optional photo attachments.
- Setting monthly budget goals.
- Receiving budgeting tips generated by the app.
- Tracking budgeting progress visually with a dynamic character and progress bar.
- Generating visual reports for better financial insight.

Design Considerations:

Iterative Improvements:

The current version of BudgetBuddy has evolved significantly from its initial prototype and Part 2 submission. Key improvements include:

Navigation Overhaul: Fixed issues with the navigation bar for smoother user experience.
Colour Scheme Redesign: Updated to create a more cohesive and visually pleasing interface.
Enhanced UX/UI: Reorganized screens for better usability and interaction.

Feature Highlights:

Registration & Login Flow:
  - Users start at the login screen.
  - New users can register accounts.
  - Upon logging in, they gain full access to the app's features.

Category Management:
  - Add, view, and manage expense categories.

Expense Logging:
  - Enter expense amount and description.
  - Attach photos for better expense documentation.
  - Save data for easy retrieval.

Budget Goal Setting:
  - Define monthly budget goals.
  - Save and update these goals as needed.

Own Feature 1 - Budget Tips Generator:
  - Located on the budget goals screen.
  - Provides simple, dynamic tips to help users stay on budget.

Own Feature 2 - Interactive Character Feedback:
  - A character on the home screen reflects the user's budgeting status:
    - 🟢 Green = Within budget.
    - 🔴 Red = Over/Under budget.
  - Visual and motivational feedback based on goal adherence.

Progress Bar Tracker:
  - Tracks the user's financial activity.
  - Dynamically updates as expenses are logged.
  - Provides a clear indication of budgeting progress.

Expense Report Page:
  - Users can select a period to generate a detailed financial report.
  - Graphs display:
    - Total spent per category.
    - Min/Max budget goals.
  - Visual insight into budgeting behavior and trends.

We made several design improvements and refinements since the prototype (Part 1) and Part 2 submission:

- Redesigned the navigation bar for improved stability.
- Harmonized the colour scheme for a more appealing and readable interface.
- Added interactive visual feedback (e.g., character color, progress bar).
- Improved responsiveness and layout consistency across all screens.

Developer Setup Instructions (Android Studio):

Follow these steps to get the project running on your local development environment:

1. Clone the Repository
   ```bash
   git clone https://github.com/your-username/BudgetBuddy.git
   cd BudgetBuddy
2.	Open the Project in Android Studio
	Launch Android Studio.
	Click on "Open" and select the cloned BudgetBuddy folder.
3.	Sync Gradle Files
	Android Studio will prompt you to sync Gradle.
	Click "Sync Now" to download dependencies.
4.	Set Up Emulator or Device
	Connect a physical Android device or set up an emulator.
	Ensure developer mode is enabled on your device.
5.	Build and Run the App
	Click the green run button.
	Select your device or emulator.
6.	Permissions
	Ensure you allow the necessary permissions (storage/camera) when prompted during app usage.
